# Moon+ Vocab milestone 1 (pipeline) implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn one book's marks from a real Moon+ backup into AnkiDroid notes, end to end, behind a plain debug screen.

**Architecture:**
- Single `:app` module. Pure-Kotlin domain code (normalization, sentence finding, excerpts, card building, status rules) is tested on the JVM.
- Android-facing pieces (zip and SQLite reading, SAF, Room, DataStore, AnkiDroid provider, OkHttp) sit behind small interfaces and are wired by hand in one `AppContainer`.
- A resumable `ImportPipeline` runs inside a WorkManager `CoroutineWorker` in the foreground.

**Tech Stack:**
- Kotlin, Jetpack Compose, Material 3 (1.5.0 line).
- Room with KSP, DataStore Preferences, WorkManager.
- OkHttp, kotlinx.serialization, jsoup.
- AnkiDroid API from JitPack.
- JUnit 4, Robolectric, MockWebServer, kotlinx-coroutines-test.

**Spec:** [`docs/superpowers/specs/2026-10-11-moon-vocab-design.md`](../specs/2026-10-11-moon-vocab-design.md). Section numbers below (§n) refer to it.

## Review Focus

1. Book paths with curly apostrophes, Cyrillic folders or decomposed Unicode (`A Hacker’s Mind.epub`, `…/кризис/…`) must still be found in the books folder. Test in Task 6.
2. A large book (Fire & Blood has 84 marks) is read and parsed once per import, not once per mark. Test in Task 12.
3. Marks with empty or whitespace-only `original`, and bookmark rows, are skipped, not turned into cards. Test in Task 3.
4. A model reply with unknown ids, duplicate ids or missing items fills only the batch's own ids. Missing ids become failed cards. Test in Task 9.
5. AnkiDroid missing or permission not granted at send time: the import still completes, and the cards stay `pending`. Test in Task 12.

### Task 3: Marks and BackupReader

**Files:**
- Create: `domain/mark/Mark.kt`, `data/backup/BackupReader.kt` (under `app/src/main/java/org/lattenwald/moonvocab/`)
- Test: `data/backup/BackupReaderTest.kt`, `data/backup/MrproFixture.kt` (test-only builder), `domain/mark/MarkKeyTest.kt`

**Interfaces:**
- Produces:

```kotlin
enum class MarkStyle { HIGHLIGHT, UNDERLINE, STRIKETHROUGH, WAVY }
data class StyleCombo(val style: MarkStyle, val color: Int)          // color = signed ARGB as stored
data class RawMark(val key: String, val bookPath: String, val bookTitle: String, val chapter: Int,
                   val position: Int, val text: String, val combo: StyleCombo, val markedAt: Long)
fun styleOf(bak: String?, underline: Int, strikethrough: Int): MarkStyle
fun markKeys(rows: List<KeyInput>): List<String>   // KeyInput(bookPath, time, text)
sealed interface BackupContents {
    data class Complete(val marks: List<RawMark>, val bookmarksSkipped: Int) : BackupContents
    data class Incomplete(val reason: String) : BackupContents
}
class BackupReader(private val cacheDir: File) { fun read(file: File): BackupContents }
```

Mark key (§5.1): SHA-256 hex of `basename(bookPath).lowercase() + "\u0000" + time`. Only when two rows share both the basename and `time`, append `"\u0000" + text`. `basename` is the part after the last `/`.

Style (§2): `bak == "1"` → WAVY. Otherwise `underline == 1` → UNDERLINE. Otherwise `strikethrough == 1` → STRIKETHROUGH. Otherwise HIGHLIGHT.

The reader:
1. Iterate `ZipInputStream` entries.
2. For each entry, peek at its first 16 bytes. Copy the entry to `cacheDir/mrbooks-<uuid>.db` only if they equal `"SQLite format 3\u0000"`.
3. Open the copy with `SQLiteDatabase.openDatabase(path, null, OPEN_READONLY)` and check that a `notes` table exists. Otherwise keep scanning.
4. Select from `notes`. Skip rows with a non-empty `bookmark`, and rows whose trimmed `original` is empty.
5. Delete the copy in `finally`.
6. If any `IOException` or `ZipException` happens before a database has been read, or no database is found, return `Incomplete`, with the reason "no database in backup" or the exception message.

### Task 4: Book text (EPUB, FB2)

**Files:**
- Create: `data/books/BookText.kt`, `data/books/EpubText.kt`, `data/books/Fb2Text.kt`
- Test: `data/books/BookTextTest.kt`, `data/books/BookFixtures.kt` (test-only builders of tiny EPUB and FB2 files)

**Interfaces:**
- Produces:

```kotlin
data class BookText(val title: String?, val author: String?, val language: String?, val chapters: List<String>)
fun readBookText(file: File, fileName: String): BookText?   // dispatch by name; null for unsupported formats
fun isoLanguage(tag: String?): String?                      // "eng" -> "en", "de-DE" -> "de", "" -> null
```

Dispatch by lowercased `fileName`:
- `.epub` (including `.fb2.epub`) → EPUB.
- `.fb2` → FB2.
- `.fb2.zip` → the first `.fb2` entry inside the zip.
- Anything else → `null`.

EPUB:
1. Open with `java.util.zip.ZipFile`.
2. Find the OPF through `META-INF/container.xml` (`rootfile/@full-path`).
3. Spine order: `itemref/@idref` → manifest `item/@href`, resolved relative to the OPF's directory, URL-decoded.
4. Each spine document's `body` text comes from jsoup `Jsoup.parse(html).body().wholeText()`.
5. `dc:language`, `dc:title` and `dc:creator` come from the OPF, parsed with `Parser.xmlParser()`.

FB2:
- Each top-level `body > section` is one chapter. Its text is the `p` elements' text joined with `\n`.
- Language, title and author come from `description > title-info`: `lang`, `book-title`, `author > first-name + last-name`.

`isoLanguage` uses `Locale.forLanguageTag(tag).language`, mapping three-letter codes through `Locale.getISOLanguages()` and `Locale(code).isO3Language`.

### Task 5: SentenceFinder

**Files:**
- Create: `domain/text/SentenceFinder.kt`
- Test: `domain/text/SentenceFinderTest.kt`

**Interfaces:**
- Consumes: `normalize` (Task 2).
- Produces:

```kotlin
sealed interface SentenceResult {
    data class Found(val sentence: String, val markStart: Int, val markEnd: Int) : SentenceResult  // span within sentence
    data object NotFound : SentenceResult
}
fun findSentence(chapters: List<String>, chapter: Int, position: Int, marked: String, locale: Locale): SentenceResult
```

Algorithm (§5.2):
1. Normalize each chapter and the marked text.
2. Find every case-insensitive occurrence of the normalized mark in each chapter.
3. Score each occurrence as `abs(normStart - position)`, plus `1_000_000` when its chapter index is below `chapter`. Keep the lowest score.
4. Map the hit back to original offsets with `originalIndex`.
5. Run `BreakIterator.getSentenceInstance(locale)` over the original chapter text, and take the sentence containing the hit's start.
6. If the mark spans past the sentence end, the sentence is the mark's own original span.
7. If the sentence has fewer than 6 words, add the previous and next sentences.
8. Trim, and return the span relative to the returned sentence.

class BookLocator(relativePaths: List<String>) { fun locate(bookPath: String): String? }   // returns a relative path
interface BookFolder { fun listRelativePaths(): List<String>; fun copyToCache(relativePath: String, cacheDir: File): File }
class SafBookFolder(private val context: Context, private val treeUri: Uri) : BookFolder

`locate`:
1. Split both paths on `/`.
2. Compare their components from the end, after `normalizeForMatch(...).lowercase()`.

`SafBookFolder` walks the tree breadth-first with `DocumentsContract.buildChildDocumentsUriUsingTree`, keeping only files. `copyToCache` streams through `contentResolver.openInputStream`. It is not unit-tested; it is a thin wrapper over SAF.

Rules (§5.3):
- `acceptModelExcerpt`:
  1. Strip `[`, `]` and `…`, then trim.
  2. The result must be a substring of `sentence` after `normalizeForMatch` on both.
  3. It must contain `focus`, and have `wordCount ≤ maxWords`.
  4. The bracketed text must equal `focus`.
  5. Return the excerpt text with the ellipses kept and the brackets removed. The focus span points at the bracketed text.
- `cutExcerpt`: centre a window of `maxWords` words on the focus, prefix and suffix `…` where words were cut. If the focus alone is longer than `maxWords`, the excerpt is the focus itself.
- `buildDraft` with `Found`:

  3. Otherwise use `acceptModelExcerpt(...) ?: cutExcerpt(...)`.
  4. `sentenceHtml` marks the focus.

For each item:
- sourceLanguage: ISO 639-1 code of the language the marked text is in.
- focus: the word or phrase worth learning, copied exactly as it appears in the sentence (same letters, same case). Usually this is the marked text. If the marked text is a long phrase or a whole sentence, pick the one word or short phrase in it that a learner most likely looked up.

- meaning: one short line in {target} saying what it means in this sentence; empty string if the translation already says it.

`run`:
1. If `backup` is set, `reader.read`. `Incomplete` returns a summary with `incompleteBackup` set.
2. Upsert books by file key (the lowercased basename). Insert marks whose combo is in `styles` (and whose book is `onlyBookFileKey`, when set) with `insertIgnoringKnown`.
3. `todo = marks.withoutCard(onlyBookId)`, ordered by `markedAt` descending.
4. Group `todo` by book. For each book, `books.text(path)` is called once per run (Review Focus 2). Find each mark's sentence with the book's `Locale(language)`.
5. Chunk into batches of 10, then for each batch:
   1. `translator.translate` with the setting's target language and excerpt limit.
   2. For each mark: if its result exists and `buildDraft` gives `Ok`, the card is `PENDING`. Otherwise it is `FAILED`, with an `error`, `word = mark.text` and empty fields.
   3. If the book's language is null, set it from the first `sourceLanguage`.
   4. `db.writeBatch` (one transaction).
   5. If `sendToAnki`, `sender.send(new PENDING ids where elsewhereDeck == null)`.
   6. Report progress.
6. `LlmException.Stop` ends the loop. Its batch writes nothing, and the summary carries `stopped`.
7. `LlmException.Failed` makes the batch's cards `FAILED` with the message.
8. After the loop, `AnkiCheck.run()`, unless AnkiDroid isn't `READY`.

`CardSender.send`:
1. `availability()` not `READY` → return `SendResult(0, n, availability)` and leave the cards `PENDING` (Review Focus 5).
2. `ensureNoteType(settings.noteTypeId, settings.noteTypeVersion)`, then store the id and version in settings.
3. For each `PENDING` card: get the deck from `deckName(...)` with `settings.deckOverride`, then `ensureDeck`, `add(mid, deckId, card.ankiFields("Title, Author"), bookTags(...))`. Update the card to `SENT` with the note id, `sentAt` and `ankiMod = null`.
4. Cards in any other status are counted as `skipped`.

`ImportWorker`:
- Reads `ImportRequest` from input data: backup path in the cache, styles as strings, book key, send flag.
- Calls `setForeground(ForegroundInfo(1, notification, ServiceInfo.FOREGROUND_SERVICE_TYPE_DATA_SYNC))`, posted to channel `import` (the channel is created in `App.onCreate()`).
- Calls `pipeline.run`, updating the notification and `setProgress` as it goes. Returns `Result.success(summaryData)`.
- Enqueued with `enqueueUniqueWork("import", ExistingWorkPolicy.KEEP, OneTimeWorkRequest)`. It is not expedited (§5.7).
