# Moon+ Vocab milestone 3 (Inbox) implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app opens on the Inbox. The user imports a backup from a sheet and watches progress. They then review the new cards grouped by book, select them with long-press and drag, swipe or bulk-send them to AnkiDroid, discard them or translate them again, and can undo any send or discard.

**Architecture:**
- Logic that can break lives in pure, unit-tested code:
  - `domain/inbox/Selection.kt`: the selection reducer and the finger-to-row geometry;
  - `domain/inbox/InboxList.kt`: grouping, ordering, filter and labels;
  - `domain/mark/StyleChoice.kt`: the import sheet's counts and default styles;
  - `domain/inbox/InboxActions.kt`: discard, restore and forget-for-retranslation.
- `CardSender` gains undo, and shares one lock with `AnkiCheck` (ticket mv-znre).
- `Settings` stops freezing defaults (ticket mv-svor).
- The Compose layer is thin and has no unit tests:
  - a theme;
  - a shell with a bottom bar;
  - the Inbox screen and its ViewModel;
  - the import sheet and its ViewModel.
  It maps state to the prototype's layout and gestures to reducer calls.

**Tech Stack:** Unchanged: Kotlin, Compose with material3 `1.5.0-beta01` (Expressive APIs), Room, DataStore, WorkManager, the AnkiDroid API, JUnit 4 and Robolectric. No new library dependencies. Fonts and icons come in as resource files.

**Spec:** [`docs/superpowers/specs/2026-10-11-moon-vocab-design.md`](../specs/2026-10-11-moon-vocab-design.md). Section numbers (§n) refer to it: §3.2 is Import, §3.3 the Inbox, §6 UI implementation and §8 Errors. Current decisions are in [`docs/DECISIONS.md`](../../DECISIONS.md).

**Layout and copy reference:** [`docs/design/prototype.html`](../../design/prototype.html), the approved working prototype (spec §3: "The prototype is the source of truth for layout, copy and motion").
- Inbox CSS runs from `.group` to `.ftool`.
- The English copy is the `en` object of `const T = {…}`.
- The row markup is in `rowHtml`, and gestures are in the `pointerdown` … `endGesture` handlers.

```kotlin
data class MarkedText(val text: String, val mark: IntRange?)
fun markedText(html: String): MarkedText

sealed interface RowLabel { data object Phrase : RowLabel; data object Invented : RowLabel; data object Failed : RowLabel; data class Elsewhere(val deck: String) : RowLabel }
data class InboxCard(val id: Long, val word: String, val grammar: String, val translation: String, val excerpt: MarkedText?,
                     val language: String?, val markedAt: Long, val failed: Boolean, val labels: List<RowLabel>)
data class InboxGroup(val bookId: Long, val title: String, val author: String?, val cards: List<InboxCard>)
data class LanguageChip(val language: String?, val count: Int)
sealed interface LanguageFilter { data object All : LanguageFilter; data class Only(val language: String?) : LanguageFilter }

```

Rules:
- **`markedText`** reads the excerpt format `markHtml` writes: escaped text with one `<span class="mark">…</span>`.
  - It decodes `&amp; &lt; &gt; &quot; &#39; &nbsp;`.
  - It drops any other tag.
  - `mark` is the decoded index range of the first `span.mark`'s text in the decoded result, or null when there is none.
  - A blank `excerptHtml` gives `excerpt = null`.
- **`inboxList` ordering:**
  - Groups are ordered by their newest card's `markedAt`, descending. Cards in a group are ordered by `markedAt` descending, then id descending. A null `markedAt` counts as 0.
  - `visibleIds` lists the cards in display order, after the filter.
- **Language chips:**
  - A card's language is its `sourceLanguage`.
  - `chips` lists every language present, with counts, by count descending, then code, and null (Other) last.
  - `chips` is empty when fewer than two languages are present.
  - A filter whose language is no longer present becomes `All`. The result's `filter` reports the filter actually applied.
- **`total`** counts every row, before the filter.
- **`labels`**, in this order:
  - `Phrase` if `widened`;
  - `Invented` if `invented`;
  - `Failed` if the status is `FAILED`;
  - `Elsewhere(deck)` if `elsewhereDeck != null`. `""` means the deck is unknown.

### Task 4: Selection reducer and drag geometry

**Files:**
- Create: `domain/inbox/Selection.kt`
- Test: `domain/inbox/SelectionTest.kt`

**Interfaces:**
- Produces:

```kotlin
data class Drag(val snapshot: Set<Long>, val order: List<Long>, val anchor: Int, val current: Int, val adding: Boolean)
data class Selection(val ids: Set<Long> = emptySet(), val active: Boolean = false, val drag: Drag? = null)
fun Selection.startDrag(order: List<Long>, id: Long): Selection
fun Selection.dragOver(id: Long): Selection
fun Selection.endDrag(): Selection
fun Selection.toggle(id: Long): Selection
fun Selection.toggleGroup(ids: List<Long>): Selection
fun Selection.toggleAll(ids: List<Long>): Selection
fun Selection.retain(existing: Set<Long>): Selection
data class RowSpan(val id: Long?, val top: Int, val bottom: Int) // id null for headers and other non-card items
fun rowAt(y: Int, rows: List<RowSpan>): Long?
fun autoScrollStep(y: Float, top: Float, bottom: Float, zone: Float, maxStep: Float): Float
```

Rules (from the prototype's `startDrag` and `applyRange`):
- **`startDrag`** makes the selection active.
  - `adding` is true when `id` is not yet selected.
  - `snapshot` is the selection before the drag, and anchor and current are both `order.indexOf(id)`. An id that isn't in `order` changes nothing.
  - `ids` becomes the snapshot with `id` added (when adding) or removed.
- **`dragOver`** moves `current` to the id's index.
  - `ids` becomes the snapshot with every id from `min(anchor, current)` to `max(anchor, current)` added (when adding) or removed. Rows outside the range return to their snapshot state.
  - An id that isn't in `order`, or a call with no drag, changes nothing.
- **`endDrag`** clears `drag`. With nothing selected, the result is `Selection()`.
- **`toggle`** flips one id. With nothing left selected, the result is `Selection()`.
- **`toggleGroup`** removes all of `ids` if they are all selected, and otherwise adds them. With nothing left selected, the result is `Selection()`.
- **`toggleAll`** works like `toggleGroup`, but the result stays active even when empty. It is the top bar's Select all. From an inactive selection it enters selection mode with everything selected.
- **`retain`** intersects `ids` and the drag's `snapshot` with `existing`. When a selection that had ids loses them all outside a drag, the result is `Selection()`.
- **`rowAt`** returns the id of the row whose `[top, bottom)` holds `y`. It returns null for headers and gaps.
- **`autoScrollStep`** returns:
  - `-min(maxStep, (top + zone - y) / 5)` when `y < top + zone`;
  - `+min(maxStep, (y - (bottom - zone)) / 5)` when `y > bottom - zone`;
  - `0` otherwise.

Rules:
- **`sheetCounts`:**
  - Each combination in `marks` gets one row: `total` is its mark count, and `new` counts its marks whose key is not in `knownKeys`.
  - Rows are sorted by `total` descending, then by style ordinal.
  - `toImport` is the new marks of the `selected` combinations plus `waiting` (the stored marks with no card, which any import resumes).
- **`defaultStyles`** is the rule now inline in `DebugViewModel.findBackup`:
  - empty `present` keeps `stored`;
  - `stored` that shares any combination with `present` stays;
  - otherwise the result is the `WAVY` combinations in `present`.
- **`colorName`** works in HSV:
  - saturation below 0.15 gives BLACK when value < 0.2, WHITE when value > 0.85, and GRAY otherwise;
  - otherwise, by hue in degrees: RED `[345, 15)`, ORANGE `[15, 45)`, YELLOW `[45, 70)`, GREEN `[70, 165)`, CYAN `[165, 195)`, BLUE `[195, 255)`, PURPLE `[255, 290)`, PINK `[290, 345)`.
- **`BackupFinder`** moves the copy, read and pick code out of `DebugViewModel.findBackup`. It keeps only the chosen file in `cacheDir/backups`.
  - `open` copies the picked document into the same directory under its display name (`OpenableColumns.DISPLAY_NAME`).
  - It reads the copy and deletes it when the backup is incomplete.
- **`Settings.write`** stores a value only when it differs from the default snapshot (the snapshot of empty preferences), and removes the key otherwise.
  - The services list keeps its rule of being written only when it changed.
  - When it is written and equals the default list, its key is removed.

  - `val events: Flow<InboxEvent>`, backed by a `Channel`:

```kotlin
sealed interface InboxEvent {
    data class Sent(val ids: List<Long>, val stayed: Int) : InboxEvent      // undo → undoSend(ids)
    data class Stayed(val count: Int) : InboxEvent                           // nothing sendable in the request
    data class Discarded(val ids: List<Long>) : InboxEvent                   // undo → restore(ids)
    data class Unavailable(val availability: AnkiAvailability) : InboxEvent
    data class SendFailed(val message: String) : InboxEvent
    data class UndoKept(val count: Int) : InboxEvent
    data class Retranslating(val count: Int) : InboxEvent
}
```

Behaviour:
- **Selection state:**
  - The ViewModel holds a `MutableStateFlow<Selection>`.
  - Every list emission applies `retain(list.visibleIds.toSet())`. The selection only ever holds visible cards, so changing the language filter drops the cards it hides.
  - `startDrag` passes the current `visibleIds` as `order`.
  - `toggleGroup(bookId)` passes that group's visible card ids. `toggleAll()` passes `visibleIds`.
- **Send:** `sender.send(ids)` runs on `io`.
  - `unavailable` gives `Unavailable`.
  - `missingFields` that aren't empty set `state.missingFields` and give `SendFailed`. A later send with an empty list clears it.
  - Any other `error` gives `SendFailed`.
  - Otherwise: `Sent(sentIds, stayed = ids.size - sentIds.size)` when something was sent, and `Stayed(ids.size)` when nothing was.
  - After a send or discard from the toolbar, the selection is cleared.
- **Discard** gives `Discarded(changedIds)`.
- **Translate again** is disabled while an import runs. Otherwise it calls `forgetForRetranslation(ids)` and enqueues `ImportWork.input(ImportRequest(backup = null, styles = emptySet(), onlyBookFileKey = null, sendToAnki = false))`. It emits `Retranslating(n)` and clears the selection.
- **Undo:**
  - Undoing `Sent` calls `undoSend`. A non-zero `kept` gives `UndoKept(kept)`; `unavailable` gives `Unavailable`.
  - Undoing `Discarded` calls `restore`.
- **Gestures** (`InboxGestures.kt`):
  - One `pointerInput` on the `LazyColumn` uses `detectDragGesturesAfterLongPress`, under `LocalViewConfiguration` overridden to `longPressTimeoutMillis = 360`.
  - Each event's row is `rowAt(y, spans)`. The spans come from `listState.layoutInfo.visibleItemsInfo`, mapping keys that are `Long` to ids and every other key to null.
  - Drag start calls `startDrag` with a `LongPress` haptic. Each new row under the finger calls `dragOver` with a `SegmentFrequentTick` haptic. End and cancel call `endDrag`.
  - During a drag, a frame loop calls `listState.scrollBy(autoScrollStep(…))` with a 72 dp zone and an 18 dp maximum, converted to px. After each scroll it repeats `dragOver` at the last finger position.
- **Selection mode** (`selection.active`):
  - The top bar becomes "N selected" (`inbox_selected`), with a close button (`clearSelection`) and Select all (`toggleAll`). Its icon shows the selected state when all visible cards are selected.
  - Rows show a leading circular check that animates in, plus `secondaryContainer` colour and full 24 dp corners when selected. A tap toggles the row.
  - Group headers show a `TriStateCheckbox`, and tapping the header toggles the group.
  - The bottom bar slides away, and a `HorizontalFloatingToolbar(expanded = true)` slides in:
    - Discard (`ic_delete`) and Translate again (`ic_refresh`) icon buttons;
    - a Send FAB, `floatingActionButton`, showing `ic_send` and `inbox_send_n`.
    - All are disabled with nothing selected. Translate again is also disabled while an import runs.
  - `BackHandler(enabled = selection.active)` clears the selection.
  - When not in selection mode, the top bar's `ic_select_all` action calls `toggleAll()`.
- **Swipe:**
  - Each card row is wrapped in `SwipeToDismissBox`, with state from `rememberSwipeToDismissBoxState(positionalThreshold = { it * 0.35f })` keyed by card id.
  - Both directions are disabled while selecting.
  - The backgrounds follow the prototype's `.sbg`. Right is `primary` with `ic_send` and `inbox_swipe_send`. Left is `errorContainer` with `inbox_swipe_discard` and `ic_delete`.
  - A `GestureThresholdActivate` haptic plays each time `targetValue` changes away from `Settled`.
  - `onDismiss` calls `send(listOf(id))` or `discard(listOf(id))`. When the send leaves the card in the Inbox (a `Stayed` or error event), call `state.reset()`.
  - Rows leave and return with `Modifier.animateItem()`.
- **Snackbars:**
  - The `SnackbarHost` lives in the Inbox `Scaffold`. Events become messages with `SnackbarDuration.Long`.
  - `Sent` and `Discarded` carry the action `inbox_undo`, which calls `undo(event)` when performed.
  - `Unavailable` text comes from the banner strings.
