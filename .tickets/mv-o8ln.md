# Redo one book's cards from its Library page

Book page action that forgets the book's unsent cards (PENDING, FAILED without a note, DELETED_IN_ANKI) and starts a resume import for that book only. Use case: a book was outside the books folder, got model-written examples, and was then moved in. Today the only way is Advanced → Forget unsent cards, which covers every book.
